# Full-Stack Data Scientist Roadmap

An open-access curriculum covering foundations through production to specialization tracks (quantitative finance, genomics).

## Roadmap

1. **Foundations** -- linear algebra, calculus, probability, statistics, optimization
2. **Systems & SE** -- algorithms, software construction, databases, distributed systems
3. **Modeling & AI** -- ML, deep learning, NLP, vision, language modeling
4. **Production** -- MLOps, inference, systems design, governance, safety
5. **Frontiers** -- quantitative finance and AI for genomics

## Features

- 45 curated courses (MIT, Stanford)
- Searchable curriculum with filters
- Local progress tracking (browser storage)
- Light/dark themes, responsive roadmap diagram
- No build step
